How to run:

  -Basically download generate_answer_template.py 
  
  -then log into ASU SOL and put in your api key from voyager into the key location in our python script
  
  -When you're in sol, place our file into the sol files and then run it using the terminal with python generate_answer_template.py
  
  -This was our first time using SOL and we realized we didn't need a requirments.txt file or any library installation since SOL already has everything setup for us.

(if you want to use our requirements go into an enviornment and do pip install -r requirements.txt, but we mainly used the SOL computer)
